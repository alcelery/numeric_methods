# Пара за 10.11.2026

Прошли основы работы с NumPy:

- **Зачем нужен NumPy:** `ndarray` — это плотный блок памяти с числами одного типа. Векторизованные операции работают в 10–100 раз быстрее циклов чистого Python.
- **Структура массива:** `shape` (форма), `ndim` (размерность), `size` (кол-во элементов), `dtype` (тип). Несовпадение `shape` — главная причина ошибок.
- **Типы данных (`dtype`):** по умолчанию `float64` (стандарт для численных методов, ~16 знаков). `float32` — только для экономии памяти (в нейросетях, картинках). Переполнение целых чисел (`int8 + 1`) NumPy не отслеживает — переходит в отрицательные.
- **Создание и формы:** `np.zeros`, `np.ones`, `np.arange`, `np.linspace`, `np.eye`. `reshape` меняет форму без копирования (если позволяет память), `-1` в `reshape` означает "посчитай сам".
- **View vs Копия:** Срезы (`a[2:5]`) — это *view* (ссылка на оригинал). Если изменишь срез, изменится и исходный массив. Чтобы получить независимую копию — используй `.copy()`.
- **Операции:** `*` — поэлементное умножение, `@` — матричное. Путать их — классическая ошибка.
- **Оси (`axis`):** `axis=0` — сворачивает строки (считает по столбцам), `axis=1` — сворачивает столбцы (считает по строкам).
- **Индексация:** срезы, списки индексов и булевы маски (`a[a > 0]`). Маски — самый частый способ фильтрации данных.
- **Broadcasting:** автоматическое растягивание массивов с разными формами при математических операциях (если размерности совместимы). Позволяет писать `X - X.mean(axis=0)` без циклов.
- **Практика:** на реальном кейсе (матрица 10x3) отработали загрузку, фильтрацию выбросов булевой маской, `reshape`, агрегацию по осям и нормировку через broadcasting.
- **Правила:** всегда проверяй `.shape` и `.dtype`; фиксируй `seed` для случайных чисел (`default_rng(42)`); для сохранения массивов используй родной формат `np.save`/`np.load`.
