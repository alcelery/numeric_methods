# Пара за 17.11.2026

Прошли основы сравнения кода: время, память и визуализация с Matplotlib:

1. **Время: `perf_counter`:** используйте `time.perf_counter()` вместо `time.time()` для точного замера одного блока кода. Всегда делайте несколько замеров, так как CPU может быть занят.
2. **Время: `timeit`:** для коротких фрагментов используйте `timeit.repeat(...)`. Он автоматически повторяет замеры, а брать нужно `min(...)`, чтобы отсечь случайные выбросы системы.
3. **Память: `tracemalloc`:** стандартный модуль для отслеживания памяти. Вызов `tracemalloc.start()` → выполнение кода → `tracemalloc.get_traced_memory()` (возвращает `(current, peak)`) → `tracemalloc.stop()`.
4. **Память: структуры:** список на миллион чисел занимает ~8 МБ, а генератор — всего несколько сотен байт. `set` и `dict` едят больше памяти, чем `list` (это плата за скорость поиска).
5. **Matplotlib: объекты:** всегда используйте объектный подход: `fig, ax = plt.subplots()`. `fig` — это холст (`figsize`), `ax` — область с осями (`plot`, `bar`, `set_xlabel`).
6. **Matplotlib: сетка графиков:** для сравнения времени и памяти рядом используйте `plt.subplots(1, 2)`. При сетке 2×2 удобно итерироваться через `for ax in axes.flat:`.
7. **Matplotlib: лог-шкала:** если разница в значениях огромная (миллисекунды vs секунды), используйте `ax.set_xscale("log")` и `ax.set_yscale("log")`. На лог-лог графике наклон линии показывает сложность алгоритма.
8. **Matplotlib: две оси Y:** метод `ax2 = ax1.twinx()` создаёт вторую ось Y для другого масштаба (например, время в мс слева, память в МБ справа), деля при этом общую ось X.
9. **Matplotlib: столбцы:** для категориальных сравнений используйте `ax.bar()`. Чтобы поставить столбцы рядом, а не друг на друге, сдвигайте их по X: `x - width`, `x`, `x + width`.
10. **Matplotlib: сохранение:** используйте `fig.savefig()`. Для отчетов добавляйте `dpi=150` (качество), `bbox_inches="tight"` (убирает пустые поля) и `transparent=True` (прозрачный фон).
11. **Сводка:** для замера времени — `perf_counter`/`timeit`, для памяти — `tracemalloc`, для графиков — `matplotlib`. Главный вывод: быстрый код не всегда экономный по памяти, ищите баланс.
